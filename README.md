# AIYA for Claude

เชื่อม Claude เข้ากับ **LINE Official Account** และ **เพจ Facebook / Instagram** ของร้านคุณ
สั่งงานด้วยภาษาไทยธรรมดา ไม่ต้องเปิดหลายหน้าจอ

ทำอะไรได้บ้าง

- ตั้งข้อความตอบอัตโนมัติใน LINE OA ทั้งข้อความต้อนรับและคำที่ลูกค้าพิมพ์บ่อย
- ร่างและตั้งเวลาบรอดแคสต์ พร้อมดูก่อนว่าจะส่งถึงกี่คน
- คิดคอนเทนต์ ร่างโพสต์ และลงปฏิทินให้เพจ
- อ่านแชทกับคอมเมนต์ที่ยังไม่ได้ตอบ แล้วร่างคำตอบให้
- ดูตัวเลขจริงว่าเดือนนี้มีคนทักเข้ามากี่คน บอทตอบได้กี่เรื่อง

## ติดตั้ง

ใน Claude Code หรือ Claude Desktop พิมพ์

```
/plugin marketplace add megenius/aiya-claude-plugin
/plugin install aiya@aiya
```

เสร็จแล้วให้เชื่อมบัญชี

```
/mcp
```

เลือก `aiya-line` และ `aiya-page` แล้วกด Authenticate จะเด้งหน้าเว็บให้ล็อกอินด้วยบัญชี AIYA ของคุณ
และเลือกร้านที่จะให้ Claude ดูแล

> **หนึ่งการเชื่อมต่อ = หนึ่งร้าน** ถ้าดูแลหลายร้าน ให้เชื่อมใหม่แล้วเลือกอีกร้านตอนล็อกอิน
> Claude จะเห็นเฉพาะข้อมูลของร้านที่เลือกไว้เท่านั้น

## ลองใช้ครั้งแรก

ลองพิมพ์สามอันนี้ดู

**1. ตั้งข้อความต้อนรับใน LINE**

> ตั้งข้อความต้อนรับใน LINE OA ให้หน่อย คนที่เพิ่งแอดเพื่อนใหม่ ให้ทักว่า
> "ยินดีต้อนรับค่ะ ร้านเปิด 9:00-18:00 ทุกวัน พิมพ์ เมนู เพื่อดูบริการได้เลยค่ะ"

Claude จะสร้างให้เป็นฉบับร่างก่อน ให้คุณอ่านแล้วค่อยสั่งเปิดใช้งาน

**2. คิดคอนเทนต์ให้เพจ**

> เดือนนี้เพจควรโพสต์อะไรบ้าง ดูจากโพสต์เก่าที่คนสนใจเยอะ แล้วร่างมา 4 โพสต์พร้อมวันที่

Claude จะดูผลงานโพสต์เก่าและปฏิทินวันสำคัญของไทยก่อน แล้วค่อยเสนอ

**3. เช็กงานค้าง**

> มีลูกค้าคนไหนทักมาแล้วยังไม่ได้ตอบบ้าง สรุปให้หน่อยว่าใครถามอะไร

Claude จะดึงห้องแชทที่ยังไม่มีคนตอบมาสรุป และข้ามห้องที่เจ้าหน้าที่กำลังคุยอยู่

## ปลอดภัยแค่ไหน

- **ยืนยันก่อนทุกครั้งที่ลูกค้าจริงจะได้รับ** ไม่ว่าจะโพสต์ขึ้นเพจ ตอบแชท หรือบรอดแคสต์ Claude จะสรุปให้ดูก่อนเสมอ แล้วรอคุณกดยืนยัน
- **ของใหม่ทุกชิ้นเป็นฉบับร่าง** ไม่มีอะไรเผยแพร่เองโดยที่คุณไม่ได้สั่ง
- **เชื่อมต่อผ่าน OAuth 2.0** ไม่ต้องเอารหัสผ่านไปใส่ที่ไหน และยกเลิกการเชื่อมต่อได้ทุกเมื่อ
- **เห็นเฉพาะร้านของคุณ** โทเค็นผูกกับร้านเดียว ไม่สามารถข้ามไปดูข้อมูลร้านอื่นได้
- **ไม่แตะข้อมูลส่วนตัวของคุณใน Claude** ปลั๊กอินนี้ไม่อ่านประวัติการสนทนา ไฟล์ที่คุณอัปโหลด หรือความจำของ Claude

## ต้องมีอะไรก่อน

- บัญชี AIYA ที่ https://oa.aiya.me หรือ https://page.aiya.me
- LINE OA หรือเพจ Facebook ที่เชื่อมเข้าระบบ AIYA แล้ว
- Claude Code หรือ Claude Desktop เวอร์ชันที่รองรับปลั๊กอิน

ยังไม่มีบัญชี ทักมาที่ https://aiya.me ได้เลย
